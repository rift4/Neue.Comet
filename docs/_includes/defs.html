{%- comment -%} Resolve the site root from the page's own depth below, so the same build works whether it is served from a domain root, a GitHub Pages project path such as /Neue.Comet/, or anything else. A hardcoded absolute root 404s every stylesheet and font everywhere except the single path it was written for. The depth is the number of path segments in page.url. Ruby's split drops trailing empty strings, so "/lab/" yields ["", "lab"] (size 2) and the root "/" yields [] (size 0); depth is therefore size - 1. The font carries no version number, so the download URL below points at whatever the most recent release is, rather than a versioned path that would have to be edited in step with every tag by hand. GitHub redirects /releases/latest to the newest published release. {%- endcomment -%} {%- assign build_version = site.time | date: "%Y%m%d%H%M%S" %}{% assign description = "Neue Comet is a typeface family" %}{% capture title %}{% if page.title %}{{ page.title }} — Neue Comet{% else %}Neue Comet font family{% endif %}{% endcapture %}{% assign _depth = page.url | split: "/" | size | minus: 1 assign url_root = "" %}{% if _depth > 0 %}{% for _i in (1.._depth) %}{% assign url_root = url_root | append: "../" %}{% endfor %}{% endif %}{% if site.baseurl %}{% assign url_root = site.baseurl | prepend: url_root %}{% endif %}{% for file in site.static_files %}{% assign _path = file.path | remove_first: "/inter" | remove_first: "/Neue.Comet" %}{% if _path == "/res/base.css" %}{% assign base_css_v = file.modified_time | date: "%Y%m%d%H%M%S" %}{% elsif _path == "/res/favicon.png" %}{% assign favicon_v = file.modified_time | date: "%Y%m%d%H%M%S" %}{% endif %}{% endfor %}{% capture download_url %}https://github.com/rift4/Neue.Comet/releases/latest/download/NeueComet.zip{% endcapture -%}
