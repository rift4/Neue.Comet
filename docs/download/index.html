Installation instructions

Show instructions for

  1. Open the "Font Book" application.
  2. In the main menu, select "File" → "Add Fonts..."
  3. Select "NeueComet.ttc", "NeueCometVariable.otf" and "NeueCometVariable-Italic.otf"
  4. Press the "Open" button

Alternatively, if you prefer not to use Font Book, you can move or copy the font files directly into ~/Library/Fonts/

  1. Open the zip file you downloaded
  2. Select "NeueComet.ttc", "NeueCometVariable.otf" and "NeueCometVariable-Italic.otf"
  3. Right-click the selected files, choose "Install for all users"

If you have a previous installation of Neue Comet, you should make sure to remove those fonts files before installing new ones. You need to install the font for all users, as some software requires fonts to be global.

  1. Create a ".fonts" directory in your home. (mkdir -p ~/.fonts)
  2. Copy "NeueComet.ttc", "NeueCometVariable.otf" and "NeueCometVariable-Italic.otf" into your .fonts directory (cp NeueComet.ttc *.ttf ~/.fonts/)

You may have to restart apps and/or your window server session.

Ubuntu Linux Q&A

Q: I installed the fonts but they don't show up
A: Try rebuilding the font database:
sudo fc-cache -f -v
Then restart your program(s).

Q: Is there a way to tell if Neue Comet was actually installed?
A: Try running: fc-list | grep "Neue Comet"

Q: ~/.fonts is an old thing. The new thing is ~/.local/share/fonts
A: Yes, that is true for recent distributions. These distros usually support ~/.fonts as well making these instructions work for everyone.

Variable & Static font files

Neue Comet fonts come in two flavors: Variable and Static (NeueCometVariable*.otf and NeueComet.ttc, respectively.)

A variable font lets you choose any weight and optical size from a single file, rather than shipping one file per weight. It is a relatively recent format and is not yet supported by all software. The variable font is therefore named "Neue Comet Variable", so it sits alongside the static fonts rather than colliding with them.

Static fonts works with older software and uses a fixed set of predefined mixtures of weight and optical size. For example "Neue Comet Display Medium" is Neue Comet with maximum optical size and a weight of 500.

Web use

If you're making a web page, you can use the following HTML and CSS: 

<!-- HTML in your document's head -->
<link rel="stylesheet" href="/fonts/neue-comet.css">

/* CSS */
:root {
  font-family: 'Neue Comet', sans-serif;
  font-feature-settings: 'liga' 1, 'calt' 1; /* fix for Chrome */
}
@supports (font-variation-settings: normal) {
  :root { font-family: NeueCometVariable, sans-serif; }
}
