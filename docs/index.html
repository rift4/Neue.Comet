Neue Comet

A variable typeface for screens. Nine weights from a thin 100 to a black 900, a true italic, and two optical sizes running from text to display.

Download ↓

2987 glyphs covering {{ lang_count }} languages across Latin, Greek and Cyrillic. Interpolation happens on two axes — weight (wght, 100–900) and optical size (opsz, 14–32) — so one file covers everything from interface text to poster sizes.

Usage

<link rel="preconnect" href="https://cdn.jsdelivr.net" crossorigin>
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/rift4/Neue.Comet@main/docs/neue-comet.css">

/* CSS */
:root { font-family: 'Neue Comet', sans-serif; }
@supports (font-variation-settings: normal) {
  :root { font-family: 'Neue Comet var', sans-serif; }
}

Served straight from the source repository via jsDelivr. Pin a release tag rather than @main in production.

Optical size runs from 14 (“text”, for small sizes) to 32 (“display”, for large). Applications with automatic optical sizing will drive it; otherwise set it in font-variation-settings.

Language support

Neue Comet covers Latin, Greek and Cyrillic — {{ lang_count }} languages in total. It does not cover Bengali, Devanagari, Tamil, Thai, Arabic, Hebrew, CJK or Hangul. For those, pair it with a font that does and set a fallback stack, rather than letting the font substitute silently.
